# SimpleEditorCamera
 Godot plugin that adds a 3D free-look camera like default Godot editor navigation (WASD for move, Right Click for camera rotation).

# How to use
1) Install through the Asset Library within Godot, look for `Simple Editor Camera`. You can also get the files by downloading this repository and putting it inside your project folder.
2) Enable the plugin in the project settings.
3) To add this new camera to a scene simply search for a node called `EditorCamera3D`
